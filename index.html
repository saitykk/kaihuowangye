📖 系统使用说明书

🛠️ 1. 日常开货操作方法

  • 极速找货：顶部搜索框支持搜中文名、拼音首字母缩写（如搜“羊肩骨”直接输 yjg）或供应商；顶部类目栏会实时显示各类目下的已选数量角标。
  • 等高无位移点货：点击右侧“选择”按钮填入默认量，可通过 “− / +” 按钮单手快速增减数量。卡片采用固定等高设计，点选时下方列表绝不跳动。
  • 单品临时备注（防误触保留）：勾选货品后，卡片第二行末尾会显示 “📝+备注” 按钮，点击即可弹窗填写备注（如“要肥一点”）。即使不小心误触取消了勾选，备注也会贴心保留，再次勾选自动恢复；仅在点击“一键清空”时彻底归零。
  • 只看已选核对：点击搜索栏旁的“只看已选”或底部“已选 X 项”胶囊，可一键过滤出今天已点的所有货品进行核对。
  • 防漏发分单结算：点击底部“一键生成结算单”后，每点击一家供应商的“单独复制”，该卡片就会持久标记为绿色“✓ 已复制待发”，多家供应商逐一发微信绝不漏发！

⚠️ 2. 极其重要的注意事项

  • 请勿清理浏览器缓存！本系统数据保存在当前手机浏览器的本地缓存中，清理缓存或卸载浏览器会导致私有修改丢失。
  • 推荐运行环境：强烈建议使用手机自带的默认浏览器打开并添加书签。
  • 如果某个货品不需要数量（如按条/块结账），在点货时把数量删成空或减到0即可，结算单上将只显示货品名称。

⚙️ 3. 数据管理与供应商预设色卡

  • 点击右上角“⚙️ 管理模式”进入后台，添加新供应商或点击已有供应商名称（带 ✏️）时，可在12色预设色卡中自由点选专属标签颜色。
  • 类目排序：在基础库中，手指按住类目前面的 ☰ 图标即可拖动调整先后顺序。
  • 新增与修改：点击右下角蓝色的 “+” 号可添加新货品；在货品列表右侧点击 “改” 或 “删” 可编辑或删除。

💾 4. 备份与多手机同步

  • 在管理模式下找到“数据导入与导出”区域，定期点击“导出备份”发到微信保存。
  • 多手机同步：把导出的 JSON 代码发给同事，粘贴到“数据导入区”点击“覆盖导入”即可同步（含供应商自定义颜色）。
